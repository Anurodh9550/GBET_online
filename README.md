# GBET Online

Standalone Next.js app for the GBET Online landing site. Host this folder on its own domain.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

Live domains are already set in `lib/site.ts`: this app is `https://online.gbte.in`, and campus links go to `https://gbte.in`. Point the Online domain at this folder when you host it.
